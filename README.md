Title :- Ride-Sharing Business Analysis using SQL

Objective

Analyze ride-sharing data to understand customer behavior, demand patterns, and driver performance.

 Analysis Performed

* Overall business performance
* Customer segmentation
* Top customer ranking using window functions
* Driver performance analysis
* Peak demand analysis
* Location-based demand
* Above-average customer identification using subqueries

 Key Insights

* The platform recorded 16,827 completed rides with an average duration of ~0.52 hours, indicating short and efficient trips.
* A small group of riders contributes significantly to total rides, identifying high-value customers.
* Ride demand peaks during evening hours, suggesting the need for optimized driver allocation.
* Driver activity is uneven, with some drivers handling significantly more trips than others.
* Certain pickup locations generate higher demand and should be prioritized.
* Above-average riders represent core users for business growth and retention strategies.

Tools Used

* SQL (SQLite)
